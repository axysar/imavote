# Growth Strategy — iMaVote

> Last updated: 2026-05-19

## Growth Model: Open-Source Led → SaaS Conversion

### Stage 1: Developer Adoption (Months 1-6)

**Channels**:
- GitHub: comprehensive README, quickstart, one-command deploy
- Hardhat ecosystem: publish as a Hardhat template/plugin
- Content: "How to add governance to your DAO in 5 minutes" blog posts
- Conference talks: ETHGlobal, Devcon, local meetups
- Hackathon bounties: sponsor governance tracks

**Metrics**: GitHub stars, forks, npm downloads, Discord members

### Stage 2: Community Growth (Months 3-9)

**Channels**:
- Delegate directory: make iMaVote the LinkedIn of governance delegates
- DAO partnerships: onboard 10 small DAOs as design partners
- Open-source contributions: accept PRs, recognize contributors
- Governance forum: host discussions about voting mechanism design

**Metrics**: Deployed instances, monthly active voters, proposals created

### Stage 3: SaaS Conversion (Months 6-12)

**Channels**:
- Hosted offering at imavote.xyz/create
- Enterprise outreach to associations, co-ops, credit unions
- Integration partnerships: wallet providers, DAO tooling platforms
- Referral program: deployed DAOs refer new DAOs

**Metrics**: MRR, paid accounts, enterprise pipeline

## Viral Mechanics

1. **Every vote is a share-worthy moment** — "I voted" shareable card with proposal summary
2. **Delegate profiles are public** — delegates share their profile to attract delegators
3. **Governance leaderboards** — most active voters, highest participation DAOs
4. **Embeddable widgets** — voting widget that any website can embed

## Retention Loops

1. **Notification-driven**: proposal created → email/push → vote → confirmation → next proposal
2. **Delegation stickiness**: once delegated, users stay engaged via delegate updates
3. **Participation streaks**: "You've voted on 5 consecutive proposals" achievement system
4. **Analytics addiction**: DAO admins check participation dashboards daily

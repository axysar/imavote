# Use Cases

## UC-1: DAO Treasury Proposal
**Actor**: DAO core contributor
**Flow**: Create proposal "Allocate 100 ETH to grants" → Set 7-day deadline → Activate → Members vote → Close → Results on-chain
**Value**: Transparent, auditable budget decisions

## UC-2: Protocol Parameter Change
**Actor**: Protocol team
**Flow**: Propose fee change → Activate → Token holders vote (weighted by balance, future) → Close → Execute on-chain
**Value**: Decentralized protocol governance

## UC-3: Board Election
**Actor**: Nonprofit executive director
**Flow**: Register board member wallets → Create "Board Chair 2026" proposal → Members vote Yes/No/Abstain → Export CSV for records
**Value**: Legally compliant, tamper-proof election

## UC-4: Community Temperature Check
**Actor**: DAO facilitator
**Flow**: Create low-stakes proposal → Activate → Members vote freely → Check participation rate → Inform next steps
**Value**: Gauge sentiment without gas burden (future: gasless)

## UC-5: Delegate Accountability
**Actor**: Protocol delegate
**Flow**: Set up delegate profile → Accept delegations → Vote on proposals → Delegators track voting history → Redelegate if unhappy
**Value**: Accountable representation with transparent track record

## UC-6: Multi-chain Governance
**Actor**: Protocol deployed on Arbitrum + Base
**Flow**: Deploy iMaVote on both chains → Voters on each chain participate → Results aggregated
**Value**: Unified governance across L2 ecosystem

## UC-7: Emergency Governance Halt
**Actor**: DAO multisig signer
**Flow**: Detect exploit → Pause voting contract → Investigate → Resume when safe
**Value**: Emergency circuit breaker prevents governance attacks during incidents
